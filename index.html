Features

一台手机，一个完整的 AI 工作台

不是简单的聊天框——Ollamaster 把 Agent、工具、记忆、插件全部装进 Android。

三种模型源

本地 Ollama 私密离线、云端 OpenAI 兼容接口、Ollama 官方云，随时切换，不绑定单一厂商。

Agent 工具循环

AI 自主规划并调用文件、命令、网页、浏览器、视觉、技能、MCP、插件等工具，直到任务完成。

浏览器自动化 + 视觉

内嵌浏览器可被 AI 打开网页、提取文本、模拟点击输入、滚动、执行 JS、截图；截图交给视觉模型「看图→点击」闭环操作。

热插拔插件系统

声明式 JSON 定义工具、页面、技能与人设卡，安装立即生效，无需重新编译，AI 自己就能造插件。

MCP 客户端

支持 Streamable HTTP 协议，连接外部 MCP 服务器，把专业工具、数据源接入你的 AI 对话。

长期记忆库

抽屉式嵌套分类记忆，AI 可读写、搜索、管理跨会话的长期记忆，越用越懂你。

技能与人格系统

自定义注入系统提示与人设卡，塑造 AI 的行为、语气与身份；人设头像自动应用到对话气泡。

模型档位

预设「速度 / 平衡 / 质量」+ 自定义档位，一键切换模型与采样参数组合，另存复用、随时重置。

提示词 Token 预算

滑块设定上下文上限（最高 200k），超限自动两阶段裁剪：先截断早期工具结果，再从最旧消息丢弃，控成本又保关键。

思考链开关

强制开启或关闭模型推理过程，并可选精简思考回传，长链推理更省 token、更快响应。

语音合成 TTS

Edge 免费 TTS 与 HTTP API 双通道，自动朗读 AI 回复，发音自然、支持中英文。

Agent Loop

让 AI 自己动手干活

Ollamaster 内置完整 Agent 循环——你只负责说需求，剩下的交给它。

1
理解任务解析你的意图与上下文
2
规划步骤拆解为可执行的工具调用
3
调用工具文件/命令/网页/浏览器/MCP
4
观察结果读取返回，修正策略
5
完成任务总结并汇报完成情况
Plugin System

热插拔，改功能不用改代码

插件就是一份 JSON：声明工具、页面、技能与人设卡，安装即生效。甚至可以由 AI 自己生成插件来扩展自己——相当于应用级「自我进化」。

  • ✓ 安装 / 卸载 / 启用 / 禁用，即时生效，无需重启
  • ✓ 工具支持 shell / HTTP / JavaScript 处理器
  • ✓ 声明式 UI JSON 自动渲染原生 Android 页面
  • ✓ 插件与源码仓库隔离，安全可控
plugin.json
{
  "id": "my_plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "tools": [{
    "name": "tool_name",
    "description": "...",
    "handler": {
      "type": "shell",
      "command": "..."
    }
  }],
  "pages": [{
    "id": "page_id",
    "label": "页面",
    "layout": { "type": "column" }
  }],
  "skills": [],
  "personas": []
}
